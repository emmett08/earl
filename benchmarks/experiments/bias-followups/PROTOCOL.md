# Developmental representation and topology follow-ups (version 0.1.0)

**Knowledge cut:** 24 September 2026. **Readiness:** specified, not executed.
This is a new cohort with its own frozen inputs and ledger. It does not alter
the 0.1.0 or 0.1.1 Stage A freezes. The case source is the same twelve
author-created synthetic families. Reuse makes this an exposed developmental
calibration, not independent confirmation. No observation in it establishes
that a real engineer experienced a cognitive bias or benefited from EAL/2.

## Questions and competing accounts

The representation estimand is the family-averaged paired difference in a
fully warranted **raw** answer between a checked EAL/2 source and its
mechanically derived typed JSON declaration graph, holding process records,
options, model, topology, output schema, system instruction and model settings
fixed. The topology estimand compares two independent general critics whose
answers undergo agreement-only synthesis with independent mechanism and rival
critics under the same synthesis rule. Each topology gets two fresh calls,
the same model, reasoning setting and per-call output ceiling. The contrast
therefore removes the one-versus-two-call difference in Stage A. Input lengths
and actual hidden reasoning or billed tokens can still differ; report them.

H1 predicts a positive representation or specialised-topology contrast in
the chosen family distribution with no increase in false strong attribution,
wrong corrections or abstention on supported cases. H2 predicts equivalent
accuracy after controlling for information and compute allocation. H3 predicts
that familiar JSON fields, role framing or agreement-only abstention alter
the answer independently of better reasoning. An apparent gain with lower
coverage, missing citations or an increased error rate does not support H1.

`followup.py` parses and statically validates every EAL/2 source with the
current repository implementation, serialises every typed declaration and
checks the JSON graph against a fresh parse. It excludes source spans and
digests, which are provenance metadata, and rejects pattern expansion, which
this renderer does not cover. The source and graph contain the same declared
argument content. They differ in length, field names and model familiarity;
the observed contrast is a rendering effect for these specific packets, not
an isolated estimate of training-set exposure. Record UTF-8 lengths and
provider input tokens by representation.

## Assignment, measurement and decisions

Each of 48 cases is crossed with the selected frozen models, two
representations and two topologies, with two calls per cell. The default
Luna/Sol schedule has 768 assigned calls; its eight-case two-family pilot has
128. Randomise call order with a fixed seed; keep the two answers independent
and exclude private fixture labels from requests. No feedback, intermediate
scores or prompt tuning is allowed within this cohort. The pilot gate checks
endpoint, schema, model identity, usage, budget and ledger integrity only.

The reference is the original author-created synthetic key. The primary
measure requires correct status, mechanism or justified non-attribution,
required record IDs, rival, defeater, defect and correction. Report false
strong attribution on negative cases, wrong correction, supported recall,
decisive coverage, refusals, missing responses, citation errors, input and
output tokens, latency and estimated cost. Preserve both individual answers:
agreement synthesis can conceal an analyst's harmful assertion. The private
role-evidence gate from Stage A is not used as the primary endpoint.

The unit for a paired contrast is a family, with four dependent variants;
repeated calls are not additional families. The implemented analysis gives
family means only after every assigned call has a valid terminal outcome.
Failure, a partial ledger, model drift or unresolved pending call prevents a
winner claim. A future confirmatory analysis must freeze a new family- and
author-disjoint reference set, independent adjudication, practical benefit
and safety margins, uncertainty method and multiplicity control before
observing its calls. The current exposed 12 families cannot certify
superiority or generalisation even if a numerical difference is large.

The pilot and full schedules are separately frozen; exact pilot request
hashes must be a subset of the full schedule. The full executor requires a
valid completed pilot and locks both ledgers. A possibly sent request remains
pending until independently reconciled. No automatic retry is permitted.
Budget reservations charge one input UTF-8 byte as a token and every allowed
output token at the configured uncached rate; this is conservative for the
plan, not a provider invoice. A missing usage record, returned model drift,
bad schema or budget breach stops the cohort. The API key is read only after
an unauthenticated endpoint preflight; neither key nor participant data
belongs in a committed archive.

## Interpretation and further discriminating work

The two general critics and two specialised critics are equal in model calls
and allocated output ceilings. Actual reasoning effort remains unobserved;
report usage and latency, and conduct a cost-matched sensitivity comparison
before attributing a gain to topology. A debate route, a host-checked
evidence packet, a prose control and a genuinely independent EAL authoring
cohort are separate factors. Cue-only swaps, relevant-evidence changes and
valid-argument controls must be authored and reviewed without contaminating
the confirmation set. The companion human protocol tests whether assistance
changes a person's decision; API performance alone cannot answer that claim.
