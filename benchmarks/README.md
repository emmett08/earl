# Benchmarks

The [GitHub Actions decision study](study-v1/README.md) specifies a prospective P/T/J/E comparison of strong prose, Toulmin prose, a meaning-equivalent EAL/2 JSON representation, and EAL/2 through the MCP server. Its [plan](study-v1/plan.json) remains `specified_not_ready`: no independently reviewed real cases, frozen model snapshots, external execution receipts or observed comparative results are present.

The single [worked GitHub workflow example](../examples/workflow-gate/README.md) is for checking the current source and host contract. Local demonstration and software tests do not require a signed study receipt and cannot establish a model-class advantage. Confirmatory real-case execution requires the study's independent review, frozen protocol and signed acquisition and assignment receipts.

The [versioned prospective runner](prospective-v1/README.md) implements the four-arm selected-acquisition path with the actual MCP stdio boundary, a typed JSON front end, injected arm policies and a durable one-attempt ledger. It rejects real stages until separately reviewed cases, model snapshots, parity tests and execution receipts are supplied. The fixed-capture diagnostic remains planned.
