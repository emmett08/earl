# Current figure design and provenance

The completed EAL/3 pilot uses fourteen retained reviewed vector figures and one new reference-undetermined profile figure. The current figures distinguish resource measurements, authored reference states, AI communication codes, ambiguity bounds and frozen statistical bounds.

The import manifest binds exact source, PDF, specification, caption and input bytes. Each standalone review retains its original semantic reconstruction, limitations and exact PDF bindings. Original mechanical audits preserve their historical absolute build paths; the local checker proves relocation by current relative input names and SHA-256 identities rather than rewriting old reviews. This checks provenance continuity and does not claim that a review of the original standalone figure validates the newly compiled journal pages.

The journal PDF is checked separately for overflow, missing references, figure count, expected current values and final rendered placement. See verification.md and manuscript-proof.json. Editable plotting recipes and input tables are retained under reproduction/, analysis/ and tables/.
