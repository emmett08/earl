# Decisions before journal submission

The article is a complete review draft for the retained principal pilot. No journal submission has been made. Its scientific conclusion is deliberately limited to the measured whole-workflow comparison. The following decisions require the actual authors or additional evidence; they must not be filled with invented facts.

1. Supply the author list, affiliations, corresponding author, contribution statement, funding and competing-interest declarations. The current PDF is an anonymous review copy, but the repository and artefact links are identifying. It is not a fully blinded submission package. Follow JSS's chosen review route before uploading.
2. Review the entire manuscript, code, cited sources and data; accept responsibility for the final content. The AI-use declaration records actual assistance and does not assert that this human review has already happened. Amend the declaration to describe the oversight actually performed.
3. Decide whether to submit this as an explicitly limited pilot or first obtain independent annotation validation. Twenty-eight recipient labels remain ambiguous, three donor labels remain ambiguous, and no human assessor error rate is available. A completed experiment-stage workflow does not remove these scientific limitations.
4. Keep the comparison at the whole-workflow level unless a new experiment supplies matched information-delivery and deterministic-computation baselines. Do not claim an isolated EAL syntax effect, reasoning-effort effect, developer productivity gain or real-project cost saving.
5. Arrange a durable archive and appropriate access to the source, data and annotation provenance. The GitHub artefact is scheduled to expire on 27 December 2026. The compact evidence snapshot is retained in Git, but repository access is not equivalent to a public research-data DOI. Check rights to disclose any artefact before public release.
6. Check the current [JSS author guide](https://www.sciencedirect.com/journal/journal-of-systems-and-software/publish/guide-for-authors), article category and submission forms. The guide returned HTTP 403 during preparation on 28 September 2026, so complete current journal-specific compliance was not verified. The [official Elsevier LaTeX guidance](https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions) and [AI policy](https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals) were consulted. Their general guidance does not establish that JSS will accept this manuscript or study design.

The abstract is below 250 words. The bibliography uses primary publications and the actual research artefact. Figures are vector plots produced by code from retained data or labelled assumptions, not fabricated evidence. The full package contains the retained input snapshot; the submission ZIP contains manuscript sources and figures only.
