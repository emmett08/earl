# Superseded developmental Kubernetes fixture

These files retain the first synthetic source, manifest, pinned catalogues
and offline result with their original bytes. The first source attached a
contention objection to the literal proposition that a prior load-test
record *reports* a threshold. A subsequent contention event can challenge
an inference to current performance, but cannot alter the earlier record's
content. The runnable study in
`benchmarks/experiments/kubernetes-host-revisions/` separates those claims
and supersedes this fixture. The old 7/7 match and byte/latency results are
implementation diagnostics for an authored graph with that semantic defect;
they are not independent evidence of a valid operating inference. The
current runner implements the revised manifest and does not rerun this
historical version.
