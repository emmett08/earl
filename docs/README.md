# Documentation scope

The language, runtime and MCP reference documents describe the current implementation. Older experiment and review documents in this directory record earlier work. Links from those documents to retired `arguments/`, `benchmarks/`, `examples/` and `paper/` assets point to the exact pre-reset commit. Files under `docs/history/` retain their original bytes and paths; consult that commit to inspect their referenced assets. None of this material is part of the new study.

The current worked case is [the workflow gate](../examples/workflow-gate/README.md). The new, unrun comparison is in [the benchmark study](../benchmarks/study-v1/README.md).
